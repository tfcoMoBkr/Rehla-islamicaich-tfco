## Tools

### `search`

Full-text search across the Holy Qur’an (in 100+ languages), the Prophetic Hadith collection, and the IslamHouse library of books, articles, fatwas, audio and video. Returns ranked results with citation URLs. Use `fetch` to read any result in full. If a multi-word phrase matches nothing, the server automatically retries it one word at a time and labels those hits `matched:` — so there is no need to re-run a failed phrase as separate words yourself, and a labelled hit matched that word, not your phrase. Hadith search covers both the words of a narration and the subject taxonomy: a query naming a topic also returns hadiths filed under it, labelled `in category:`, and names the category so `browse_hadith_categories` can list the rest. Results are drawn from published texts of established Islamic institutions; this tool retrieves and cites sources, it does not issue religious rulings.

```json
{
  "type": "object",
  "properties": {
    "query": {
      "type": "string",
      "minLength": 1,
      "description": "Search terms. Works in Arabic and in any supported translation language."
    },
    "sources": {
      "type": "array",
      "items": {
        "type": "string",
        "enum": [
          "quran",
          "hadith",
          "library"
        ]
      },
      "description": "Limit to specific corpora. Omit to search all three."
    },
    "language": {
      "type": "string",
      "description": "ISO language code for results, e.g. \"en\", \"ar\", \"ur\", \"id\". Defaults to \"en\"."
    },
    "limit": {
      "type": "integer",
      "minimum": 1,
      "maximum": 25,
      "description": "Maximum results (1-25, default 10)."
    }
  },
  "required": [
    "query"
  ],
  "additionalProperties": false,
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

### `fetch`

Retrieve the full text of a single document by the id returned from `search`. For a Qur’anic verse this returns the Arabic alongside its translation; for a hadith, the text with its narrator, authenticity grade and scholarly explanation; for a library item, its description, authors and download links.

```json
{
  "type": "object",
  "properties": {
    "id": {
      "type": "string",
      "minLength": 1,
      "description": "Document id from a `search` result. Do not construct these by hand."
    }
  },
  "required": [
    "id"
  ],
  "additionalProperties": false,
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

### `get_quran_verses`

Retrieve one or more verses of the Holy Qur’an with the Arabic text and a translation. Give a surah (1-114) and optionally a verse or verse range; omit both to get the whole surah. Use `list_quran_translations` to discover translation keys for a language.

```json
{
  "type": "object",
  "properties": {
    "surah": {
      "type": "integer",
      "minimum": 1,
      "maximum": 114,
      "description": "Surah number, 1-114."
    },
    "ayah": {
      "type": "integer",
      "minimum": 1,
      "description": "First verse. Omit for the whole surah."
    },
    "through": {
      "type": "integer",
      "minimum": 1,
      "description": "Last verse of a range. Requires `ayah`."
    },
    "translation_key": {
      "type": "string",
      "description": "QuranEnc translation key, e.g. \"english_saheeh\"."
    },
    "language": {
      "type": "string",
      "description": "ISO language code; picks a default translation. Default \"en\"."
    }
  },
  "required": [
    "surah"
  ],
  "additionalProperties": false,
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

### `list_quran_translations`

List available Qur’an translations and their keys. 75 translations across 56 languages. Pass a language code to narrow the list. The returned `key` is what `get_quran_verses` accepts.

```json
{
  "type": "object",
  "properties": {
    "language": {
      "type": "string",
      "description": "ISO code to filter by, e.g. \"ur\". Omit for all translations."
    }
  },
  "additionalProperties": false,
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

### `get_quran_audio`

Get the MP3 recitation URL for a single verse of the Holy Qur’an. One verse per call: there is no whole-surah audio, so ask for a range of verses one at a time. Reciters: hudhaify, alafasy, husary, abdulbasit, sudais, shuraym, minshawy, tablaway (default hudhaify). Returns a direct link; it does not play or download the file.

```json
{
  "type": "object",
  "properties": {
    "surah": {
      "type": "integer",
      "minimum": 1,
      "maximum": 114,
      "description": "Surah number, 1-114."
    },
    "ayah": {
      "type": "integer",
      "minimum": 1,
      "description": "Verse number within the surah. One verse per call."
    },
    "reciter": {
      "type": "string",
      "enum": [
        "hudhaify",
        "alafasy",
        "husary",
        "abdulbasit",
        "sudais",
        "shuraym",
        "minshawy",
        "tablaway"
      ],
      "description": "Reciter for the recitation. Default \"hudhaify\"."
    },
    "language": {
      "type": "string",
      "description": "ISO code for the verse page link. Default \"en\"."
    }
  },
  "required": [
    "surah",
    "ayah"
  ],
  "additionalProperties": false,
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

### `get_hadith`

Retrieve a single hadith by its HadeethEnc id, with the narration, its narrator, the authenticity grade assigned by hadith scholars, and the scholarly explanation. Pass several language codes to get the same hadith side by side in each. Every response states which languages that hadith is actually published in, taken from HadeethEnc’s own record — read that list rather than estimating it. Ids are identical in every language, so a language that returns nothing has no published translation; the hadith is not filed under a different number there. Find ids with `search` or `browse_hadith_categories`.

```json
{
  "type": "object",
  "properties": {
    "id": {
      "type": [
        "string",
        "number"
      ],
      "description": "HadeethEnc hadith id, e.g. 4560."
    },
    "language": {
      "anyOf": [
        {
          "type": "string"
        },
        {
          "type": "array",
          "items": {
            "type": "string"
          },
          "minItems": 1,
          "maxItems": 8
        }
      ],
      "description": "ISO language code, or up to 8 of them to get the same hadith in each. Default \"en\"."
    }
  },
  "required": [
    "id"
  ],
  "additionalProperties": false,
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

### `browse_hadith_categories`

Browse the Prophetic Hadith collection by subject. With no arguments, lists the 7 main categories (Belief, Jurisprudence, Manners, and so on) with hadith counts. Pass a category_id to list its sub-categories and the hadiths it contains, which can then be read with `get_hadith`. A category browsed in one language lists only the hadiths published in that language, so both the counts and the membership differ between languages.

```json
{
  "type": "object",
  "properties": {
    "category_id": {
      "type": "integer",
      "description": "Category to list hadiths from. Omit for the top-level categories."
    },
    "language": {
      "type": "string",
      "description": "ISO language code. Default \"en\"."
    },
    "page": {
      "type": "integer",
      "minimum": 1,
      "description": "Page number, default 1."
    },
    "per_page": {
      "type": "integer",
      "minimum": 1,
      "maximum": 50,
      "description": "Results per page, max 50, default 20."
    }
  },
  "additionalProperties": false,
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

### `browse_library`

Browse the IslamHouse library of books, articles, fatwas, audio and video in 130+ languages. Filter by title, subject category or author, sort by latest, and page through results (12 per page). Each result shows its author and subject together with the ids that `author` and `subject_category` accept. For a keyword search across all corpora at once, use `search` instead.

```json
{
  "type": "object",
  "properties": {
    "name": {
      "type": "string",
      "description": "Filter by title text."
    },
    "subject_category": {
      "type": [
        "string",
        "number"
      ],
      "description": "Subject category id. Ids are language-specific: take them from the \"category #id\" shown in this tool’s results for the same language, or from `list_library_categories` for Arabic."
    },
    "author": {
      "type": [
        "string",
        "number"
      ],
      "description": "Author id, as shown as \"author #id\" in this tool’s results."
    },
    "sort_by": {
      "type": "string",
      "enum": [
        "latest"
      ],
      "description": "Sort order. Omit for default relevance/priority."
    },
    "language": {
      "type": "string",
      "description": "ISO language code. Default \"en\"."
    },
    "page": {
      "type": "integer",
      "minimum": 1,
      "description": "Page number, default 1. Upstream serves 12 items per page."
    }
  },
  "additionalProperties": false,
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

### `get_library_item`

Retrieve a single IslamHouse library item by id: its description, authors, subject categories and direct download links for any attached files (PDF, audio, video).

```json
{
  "type": "object",
  "properties": {
    "id": {
      "type": [
        "string",
        "number"
      ],
      "description": "Item id from `browse_library` or `search`."
    },
    "language": {
      "type": "string",
      "description": "ISO language code. Default \"en\"."
    }
  },
  "required": [
    "id"
  ],
  "additionalProperties": false,
  "$schema": "http://json-schema.org/draft-07/schema#"
}
```

### `list_library_categories`

List the subject taxonomy of the IslamHouse library — main categories with their sub-categories — and the ids `browse_library` accepts as `subject_category`. Upstream maintains this taxonomy in Arabic only, so these ids filter Arabic content (`language: "ar"`). For any other language, use the "category #id" shown next to each `browse_library` result.

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "properties": {}
}
```

### `list_languages`

List the languages Islamic content is available in, with the number of items in each. Use the returned codes as the `language` argument to other tools.

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "properties": {}
}
```
